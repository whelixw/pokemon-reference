# Item icons

`itemicons-sheet.png` is the Pokémon Showdown public item sprite sheet, retrieved 28 October 2026 from https://play.pokemonshowdown.com/sprites/itemicons-sheet.png.

The pinned item data provides `spritenum`. Tiles are 24×24 pixels in 16 columns, matching Showdown’s `getItemIcon` renderer. The dashboard extracts tiles locally for offline rendering; all 166 current item tiles were checked for non-empty content.
